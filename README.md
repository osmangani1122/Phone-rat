# 📱 Android Remote Device Node (Termux + Firebase)

A lightweight background client for controlling Android hardware remotely using Firebase Realtime Database and Termux API.

### 🚀 How to Setup on Android (Termux):

1. Install **Termux** and **Termux:API** from [F-Droid](https://f-droid.org/).
2. Open Termux and run:
```bash
pkg update -y && pkg install -y python termux-api git
git clone https://github.com/আপনার_ইউজারনেম/আপনার_রেপোর_নাম.git
cd আপনার_রেপোর_নাম
python client.py
